🚀 Dashboard Gráfico Moderno em Python (tkinter)
Uma aplicação de desktop moderna desenvolvida em Python que demonstra uma interface gráfica (GUI) elegante com tema escuro (Dark Mode), navegação por abas e componentes personalizados utilizando a biblioteca nativa tkinter e ttk.

🎯 Objetivo
O objetivo principal deste projeto é fornecer um modelo (boilerplate) robusto e esteticamente apelativo para o desenvolvimento de aplicações de desktop em Python. A interface simula um painel de controlo completo, combinando um ecrã de início de sessão (Login) interativo com um painel principal (Dashboard) rico em controlos visuais, tabelas de dados, gráficos em Canvas e formulários de configuração.

⚙️ Requisitos
Para executar este projeto, necessita de ter instalado no seu sistema:

Python (versão 3.8 ou superior recomendada).

Bibliotecas padrão do Python incluídas por defeito (o projeto utiliza tkinter, json, etc., pelo que não são necessárias dependências externas adicionais via pip).

📦 Instalação
Clone o repositório ou descarregue os ficheiros do projeto para a sua máquina local:

Bash
git clone <url-do-repositorio>
cd <nome-do-repositorio>
Certifique-se de que se encontra na pasta raiz do projeto, onde estão localizados os ficheiros main.py, interface.py e metacritic_games.json.

▶️ Execução
Para iniciar a aplicação, execute o script principal a partir do seu terminal:

Bash
python main.py
💡 Utilização
Ecrã de Login:

Ao iniciar a aplicação, ser-lhe-á apresentado um ecrã de autenticação com campos estilizados para introduzir o seu e-mail e palavra-passe.

Clique no botão de entrar para aceder ao painel principal (a interface simula a transição de ecrã).

Painel Principal (Dashboard):

Abas de Navegação: Utilize o menu superior para alternar entre as diferentes secções do painel.

Tabelas e Listas: Visualize dados tabulares (como a listagem de jogos carregada a partir do ficheiro metacritic_games.json) e interaja com listas de registos.

Controlos de Formulário: Explore componentes como caixas de seleção, botões de rádio, seletores de escala (slider), barras de progresso e menus suspensos (Combobox).

Área Gráfica: Visualize demonstrações visuais e elementos desenhados dinamicamente na área de Canvas.

⚠️ Limitações
Âmbito Visual e Demonstrativo: A aplicação foi concebida primariamente como uma demonstração de design de interface e componentes gráficos em tkinter, pelo que as funcionalidades de backend (como autenticação real de utilizadores ou persistência de dados de formulário) são simuladas.

Dependência de Sistema Operativo: Embora o tkinter seja multiplataforma (compatível com Windows, macOS e Linux), a renderização exata de certos efeitos visuais personalizados (como cantos arredondados e fontes) pode variar ligeiramente dependendo do sistema operativo e do gestor de janelas utilizado.
